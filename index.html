Files in the cloud (iCloud, Google Drive, OneDrive, Dropbox)
  1. iPhone / iPad: tap the box above → Choose File (or Browse) → pick iCloud Drive, Google Drive, OneDrive or Dropbox under Locations.
  2. Google Drive, OneDrive or Dropbox missing there? Install its app once, then in the Files app: Browse → ⋯ → Edit → switch it on.
  3. Android: tap the box → ☰ (top left) → Drive, OneDrive or Dropbox.
  4. A Google Docs document (not a Word file): in Google Drive open it → ⋮ → Share & export → Save as Word (.docx), then choose that copy. Apple Pages: Share → Export → Word or PDF.
